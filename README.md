# DIWAN — النسخة الثابتة

موقع DIWAN يعمل مباشرة بفتح `index.html` ولا يحتاج Node.js أو Python أو أوامر تشغيل.

## Discord
- السيرفر: https://discord.gg/FcSqsCtBJ
- الشكاوى والطلبات: https://discord.gg/gEukfd7v5
- نماذج التواصل والاقتراحات ترسل إلى Discord باستخدام Webhook.

> ملاحظة أمنية: رابط الـWebhook موجود داخل ملفات الموقع لأنه موقع Static. أي شخص يستطيع رؤية ملفات الموقع قد يستطيع استخدامه. عند نشر الموقع بشكل عام يُفضّل استبدال الـWebhook لاحقًا وربطه عبر خدمة وسيطة آمنة.
